# ⚡ ApostaMaster - Simulador de Apostas

Um aplicativo web moderno de simulação de apostas desenvolvido com **HTML5, CSS3 e JavaScript Vanilla**.

> ⚠️ **Aviso:** Este projeto é apenas para fins educacionais e entretenimento. Todos os saldos e transações são 100% fictícios.

---

## 🎮 Jogos Inclusos

1. **🚀 Crash Multiplier (Foguetinho):**
   - Multiplicador dinâmico em tempo real.
   - Decida o momento exato de realizar o cashout antes do foguete explodir.

2. **🎯 Roleta Double:**
   - Apostas clássicas em **Vermelho (2x)**, **Preto (2x)** ou **Dourado (14x)**.
   - Animação horizontal sincronizada com parada precisa.

3. **🪙 Cara ou Coroa (Coin Flip):**
   - Escolha Cara ou Coroa.
   - Efeito visual 3D de lançamento de moeda com física de rotação.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**
- **CSS3 Moderno**: Flexbox, CSS Grid, Glassmorphism e animações CSS 3D
- **JavaScript Vanilla (ES6+)**: Controle de estados, cálculos de probabilidade e manipulação do DOM
- **Web Audio API**: Efeitos sonoros sintetizados nativamente sem necessidade de bibliotecas externas
- **LocalStorage**: Persistência do saldo fictício e histórico do usuário

---

## 🚀 Como Executar

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
git clone https://github.com/guilhermeladislau/apostas.git
cd apostas
```

Ou simplesmente dê um duplo clique no arquivo `index.html`.
